# Dialoging Support Bot

Телеграм-бот для Dialoging: поддержка, FAQ, оплата подписки через ЮKassa.
Работает на **aiogram 3** + **YooKassa**, поддерживает русский и английский.

Ниже — пошаговая инструкция для запуска **без опыта программирования**,
через бесплатный/дешёвый хостинг Railway.

---

## Шаг 1. Получите токен бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456:AAAAxxxxxxxx` — сохраните его.

## Шаг 2. Узнайте ID админ-чата (куда будут падать обращения)

1. Найдите бота **@userinfobot** и напишите ему `/start` — он покажет ваш ID.
2. Либо создайте отдельную группу для поддержки, добавьте туда бота
   и узнайте ID группы через **@getidsbot** (там будет число со знаком «-»).
3. Это значение — `ADMIN_CHAT_ID`.

## Шаг 3. Получите данные ЮKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) как ИП/самозанятый/ООО
   (ЮKassa требует юрлицо для приёма платежей — без этого пункта карты РФ не подключить).
2. В личном кабинете: **Настройки → API** — скопируйте `shopId` и `Секретный ключ`.
3. Для тестов сначала используйте **тестовый магазин** (выдаётся автоматически при регистрации).

## Шаг 4. Разместите бота на Railway (хостинг)

Railway — самый простой вариант для новичка: не нужен свой сервер, всё через браузер.

1. Зайдите на [railway.app](https://railway.app), зарегистрируйтесь через GitHub.
2. Загрузите папку `dialoging_bot` к себе на GitHub одним из способов:
   - самый простой: на [github.com/new](https://github.com/new) создайте репозиторий,
     затем на странице репозитория нажмите **Add file → Upload files** и перетащите
     все файлы из папки `dialoging_bot`.
3. В Railway нажмите **New Project → Deploy from GitHub repo**, выберите этот репозиторий.
4. Во вкладке **Variables** добавьте переменные (те же имена, что в `.env.example`):
   - `BOT_TOKEN`
   - `ADMIN_CHAT_ID`
   - `YOOKASSA_SHOP_ID`
   - `YOOKASSA_SECRET_KEY`
   - `RETURN_URL`
5. Во вкладке **Settings** укажите команду запуска (Start Command):
   ```
   pip install -r requirements.txt && python -m bot.main
   ```
6. Нажмите **Deploy**. В логах должно появиться `Start polling` — бот запущен и работает 24/7.

> Важно: тип сервиса должен быть постоянно работающим процессом ("worker"), а не веб-сайтом —
> Railway это определяет автоматически, отдельного домена/SSL не требуется, бот сам
> проверяет оплату каждую минуту.

## Как это работает

- **Поддержка**: пользователь нажимает «Поддержка», пишет вопрос — он приходит вам
  в `ADMIN_CHAT_ID`. Чтобы ответить — сделайте **Reply** (ответ) на это сообщение
  прямо в Telegram, бот перешлёт ваш текст пользователю.
- **FAQ**: статичный текст, который можно поменять в `bot/texts.py` (ключ `faq_text`).
- **Подписка**: пользователь выбирает тариф → бот создаёт счёт в ЮKassa и присылает ссылку
  на оплату → после оплаты (по кнопке «Проверить оплату» или автоматически, раз в минуту)
  подписка активируется.

## Что можно поменять самому (без программиста)

| Что | Где |
|---|---|
| Цены и сроки тарифов | `bot/config.py`, словарь `PLANS` |
| Тексты бота (RU/EN) | `bot/texts.py` |
| Текст FAQ | `bot/texts.py`, ключ `faq_text` |

## Локальный запуск (для теста на своём компьютере)

```bash
pip install -r requirements.txt
cp .env.example .env   # и заполните своими значениями
python -m bot.main
```

## Дальнейшие шаги, которые стоит обсудить отдельно

- Переключение ЮKassa из тестового режима в боевой (после проверки, что всё работает).
- Уведомление об окончании подписки за N дней (сейчас бот проверяет только на входе).
- Если объём обращений вырастет — можно подключить полноценную тикет-систему вместо
  пересылки сообщений в чат.
